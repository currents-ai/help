# Manage Users and Permissions for Agents

This guide explains how to invite new team members to your workspace and control their access to specific Agents. You will learn how to assign Agent-level permissions during the invitation process and how to manage or revoke these permissions later.

## Add or remove an user for agent

### 1. Access User Settings
To begin managing team members, navigate to the **Settings** menu located in the bottom left corner of the dashboard. From the expanded menu, click on **Users** to open the user management dashboard where you can view existing members and their statuses.

![Access User Settings](/img/help/users-and-permission/manage-users-and-permissions-for-agents/step-1.png)

### 2. Invite User and Assign Agent Access
Click the **Invite Users** button and enter the team member's email address. Select the appropriate **Role** (e.g., User), and then select the specific Agents (e.g., "Test Agent") you wish to grant them access to. This ensures the user is automatically added to the Agent's member list upon invitation.

![Invite User and Assign Agent Access](/img/help/users-and-permission/manage-users-and-permissions-for-agents/step-2.png)

### 3. Verify Agent Membership
To confirm a user has access to a specific workflow, navigate to the **Agents** tab and select the specific Agent. Click on the **Members** tab to view the list of authorized users; the newly invited user should appear here with their assigned role (e.g., Writer).

![Verify Agent Membership](/img/help/users-and-permission/manage-users-and-permissions-for-agents/step-3.png)

### 4. Remove User from an Agent
If you need to revoke access to a specific Agent without removing the user from the entire workspace, go to the Agent's **Members** tab. Locate the specific user in the list and click the **Remove User** button on the right side of their row.

![Remove User from an Agent](/img/help/users-and-permission/manage-users-and-permissions-for-agents/step-4.png)

### 5. Revoke System Access
To completely remove a user from the workspace, return to **Settings > Users**. Locate the user in the main list and click the **Delete** (trash bin icon) or edit actions to revoke their access to the platform entirely.

![Revoke System Access](/img/help/users-and-permission/manage-users-and-permissions-for-agents/step-5.png)


## Edit User Roles (Admin & Owner)

### 1. Open User Editing Menu
Navigate to the **Settings > Users** page. Locate the user you wish to modify in the list and click the **pencil icon** (Edit User) on the right side of their row to open the configuration modal.

![Open User Editing Menu](/img/help/users-and-permission/edit-user-roles/step-1.png)

### 2. Select Admin Role and Review Permissions
Click the **Role** dropdown menu. When selecting a role like **Admin**, the system displays a description of the associated permissions, such as the ability to create and manage resources or invite other users. This helps ensure you are granting the appropriate level of access.

![Select Admin Role and Review Permissions](/img/help/users-and-permission/edit-user-roles/step-2.png)

### 3. Assign Owner Privileges
To grant full control over the workspace, select **Owner** from the dropdown list. This role includes all Admin capabilities plus the ability to manage billing and delete the workspace. Ensure this level of access is intended before proceeding.

![Assign Owner Privileges](/img/help/users-and-permission/edit-user-roles/step-3.png)

### 4. Save Role Changes
Once the desired role (Admin or Owner) is selected, click the **Update Role** button at the bottom of the modal to apply the changes. The user's permissions will be updated immediately.

![Save Role Changes](/img/help/users-and-permission/edit-user-roles/step-4.png)
